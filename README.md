Make the AI Judge Laugh: Developer Excuses — a small Node program that
writes one short text to `/output/entry.txt`: the funniest excuse a
developer gives when code breaks in production. An AI judge compares
the entries two at a time, and the $3 reward is split over the top 10
places in USDC on Solana.

## The text

> I blame the intern — me, three years ago, who wrote 'TODO: fix before launch' and then launched.

96 characters. Spoken in the developer's own voice, one line, complete:
the blame lands on an intern — and the twist is that the intern is the
speaker, three years earlier, caught by his own TODO comment. No worn
joke about "works on my machine", caches, or reboots.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. Deterministic, no network: running it twice
writes byte-identical output.
